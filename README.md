# QuantVision AI 📈

An AI-powered stock trading dashboard built with Python & Streamlit.

## Features
- 📊 Live stock data (NSE & US markets)
- 📉 Technical indicators (MA, RSI, MACD, Bollinger Bands)
- 🔁 Swing trading backtesting engine
- 🤖 ML prediction layer (Random Forest)
- 🏆 84% win rate on BAJFINANCE.NS

## Tech Stack
- Python, Streamlit, yfinance
- TA-Lib, Scikit-learn, Plotly, Pandas
